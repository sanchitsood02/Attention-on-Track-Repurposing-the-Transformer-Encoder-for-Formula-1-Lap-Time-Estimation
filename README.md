# Attention-on-Track-Repurposing-the-Transformer-Encoder-for-Formula-1-Lap-Time-Estimation

This project examines “Attention Is All You Need” (Vaswani et al., 2017), the paper that introduced the Transformer and replaced recurrence and convolution with self-attention to model sequence dependencies in parallel. The original encoder–decoder architecture, its multi-head scaled dot-product attention, and its sinusoidal positional encoding are reviewed and reproduced on the WMT 2014 machine-translation task to establish a faithful baseline. The contribution (Route 1: New Application) repurposes the Transformer encoder for a domain the paper never tested Formula 1 lap telemetry. Each clean lap is tokenised into 50 mini-sector tokens carrying aggregated speed, throttle, brake, gear and DRS signals, and the encoder is fitted with a regression head to estimate lap time, with tyre compound, fuel load and track state controlled for. Predictive accuracy is compared against LSTM and XGBoost baselines using MAE and RMSE, and the learned attention weights are inspected for interpretable concentration on braking zones and corner exits.
